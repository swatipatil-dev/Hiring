# =====================================================
# HIREFLOW — cPanel / self-hosted Linux dependency set
# =====================================================
# Install with:
#   pip install -r requirements-cpanel.txt
#
# Differences from requirements.txt and why they exist:
#
# 1. CPU-only torch. Plain `pip install torch==2.1.1` pulls the CUDA build and
#    ~2 GB of nvidia-* wheels that are dead weight on a CPU-only server. The
#    extra index below serves the CPU wheels instead (same approach as the
#    Cloud Run Dockerfile).
# 2. Dropped packages with zero import sites in the codebase — verified, not
#    assumed. psycopg2-binary additionally FAILS to build without pg_config,
#    so leaving it in breaks the install outright on a box with no Postgres.
# 3. Added dnspython, which routes/superadmin_routes.py imports for DNS-TXT
#    custom-domain verification but which requirements.txt never declared.
# 4. Dropped google-cloud-storage: only used by the STORAGE_BACKEND=gcs branch
#    in src/services/storage.py. Self-hosted uses STORAGE_BACKEND=local.
#    Re-add it if you ever point storage back at a bucket.
# 5. Dropped deepface. requirements.txt lists it under "Proctoring AI
#    dependencies", but it has ZERO import sites — face recognition is done
#    entirely with OpenCV DNN (SFace + YuNet ONNX models shipped in
#    proctoring/models/), see core/face_analyzer.py:30-31. deepface pulls
#    TensorFlow transitively (~1.5 GB installed) for nothing. Nothing in the
#    codebase imports tensorflow or keras either — verified.
#
# Kept deliberately: torch / sentence-transformers (semantic ATS scoring),
# mediapipe / opencv-python / ultralytics (AI proctoring), google-genai (all
# LLM features), redis + rq (background email + judge queues). Dropping any of
# those disables a feature — see the fallbacks noted inline below.
#
# System packages these need (not installable via pip):
#   mesa-libGL, mesa-libEGL, glib2   → opencv / mediapipe
#   libsndfile, ffmpeg               → audio proctoring
#   tesseract                        → pytesseract OCR for scanned resumes
#   docker CLI + daemon              → coding judge (JUDGE_BACKEND=docker)

--extra-index-url https://download.pytorch.org/whl/cpu
